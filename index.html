How I work

Built with AI, checked like an engineer.

Start from the problem

I find what is costing the business money or time, decide what to build, and write down what done looks like.

Build with Claude Code

I build with AI coding tools. I set the requirements, review the changes, and decide how each system behaves when something fails.

Test against the real thing

Real bookings, real payments and real emails before launch. The booking engine was tested live with three customers booking one slot at the same moment: one got it, two were told it was taken.

Guard it after launch

Each site carries its own checks. Smart Space's build runs 41 of them before every deploy, from consent and conversion tracking to booking dates.
